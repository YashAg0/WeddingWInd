This document outlines the multi-year engineering roadmap for scaling **WeddingWithIndia** from public launch to international market dominance.

## 2. Quarterly Milestones

### Phase 1: Post-Launch Stability & Infrastructure Hardening (Q3 2026)
- [x] Public launch sign-off with 43 compiled Next.js routes.
- [ ] Integration of Sentry for real-time client & server error tracking.
- [ ] Implementation of Upstash Redis L2 caching for high-traffic wedding search queries.
- [ ] Setting up Datadog / New Relic APM for latency monitoring.

### Phase 2: Hyper-Growth & Agent Network Scaling (Q4 2026)
- [ ] Automated Stripe Connect Payouts for host 78% shares and agent tiered commission (₹500-₹500)s.
- [ ] Multi-Language Localization (`next-intl`) supporting French, German, Spanish, and Japanese.
- [ ] Automated Playwright E2E test suite running in GitHub Actions CI/CD pipeline.
- [ ] Expand agent referral portal with custom marketing kits and collateral downloads.

### Phase 3: AI Concierge & Cultural Assistant (Q1 2027)
- [ ] Launch AI Cultural Concierge chatbot assisting guests with attire rules, gift etiquette, and ceremony timelines.
- [ ] Vector similarity recommendation engine (Pinecone + PgVector) for personalized wedding matching.
- [ ] Dynamic currency hedging protection for international bank transfers.

### Phase 4: Enterprise Scale & Native Mobile Ecosystem (Q2 2027)
- [ ] Release native iOS & Android applications with offline digital QR Guest Pass storage in Apple Wallet / Google Wallet.
- [ ] Integration of embedded travel medical insurance at checkout.
- [ ] Enterprise host portal for multi-venue luxury wedding management groups in India.
